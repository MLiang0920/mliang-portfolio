核心功能

🎴单词卡

SM-2 间隔重复算法（Anki 同源），系统自动安排最佳复习时机。4 套词库从零基础到六级全覆盖。

🎧听力精听

5 套双语材料，逐句循环播放 + 全文连播 + 四档语速。点击任意句子即播即停。

💬AI 陪练

接入 DeepSeek / 通义 / 智谱任一大模型。自由聊天 / 场景角色扮演 / 作文批改 / 语法讲解，四模式四难度。

✍️默写小窗

桌面独立悬浮工具。三等级：照输→看中文写→听音盲写。40%概率优先出错题，强化薄弱环节。

📖查词 & 生词本

内置词库秒查 + 在线 API 兜底。一键加入生词本，跨模块联动——默写/单词卡自动用生词本出题。

🔊原生 TTS 朗读

APK 调用 Android 系统 TTS 引擎（Capacitor 原生插件）。网页端降级到 Web Speech API，双通道保证全平台出声。
