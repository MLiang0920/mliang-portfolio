今日推荐

推荐学习路径：单词卡 → 播客 → AI 陪练。每天 25 分钟，4 周能明显感觉到听力提升。

功能一览

  • 单词卡：8 个内置词包共 近 2000 词（入门 / 口语 / 四级 / 六级 / 雅思 / 托福 / 新闻 / 商务），采用 SM-2 间隔重复算法（Anki 同源）。
  • 听力精听 & 播客电台：内置 7 篇场景听力 + 6 集英语播客（成长思维、睡眠、气候、专注、善良、理财），逐段朗读+翻译显隐。
  • 广播级朗读：默认语速 1.0（标准播音语速），优先选 神经/自然语音（Aria / Jenny / Google US）。
  • AI 陪练：支持 OpenAI / DeepSeek / 通义千问 / 智谱 GLM，自由聊天、角色扮演、作文批改、语法讲解。
  • 查词：内置 2000+ 词 + 在线 DictionaryAPI + 备用词典三重兜底；一键加入生词本。
  • 词包市场：支持导入自定义 JSON 词包（格式兼容 Anki 导出、ECDICT 等）。

📦 词包市场

加载内置词包 · 导入自定义词包 · 支持 [[word, 音标, 词性, 释义, 例句]] JSON 格式

词包格式说明

支持两种格式，你也可以直接把 Anki 或扇贝导出的单词转一下：

// 格式 1：简单数组
[
  ["hello", "/həˈloʊ/", "int.", "你好", "Hello, world!"],
  ["book",  "/bʊk/",    "n.",   "书",    "A good book."]
]

// 格式 2：带元数据
{
  "id": "my-vocab",
  "name": "我的自定义词包",
  "words": [
    ["hello", "/həˈloʊ/", "int.", "你好", "Hello!"]
  ]
}

AI 接口配置

支持所有 OpenAI 兼容接口。国内推荐：
• DeepSeek：endpoint https://api.deepseek.com/v1/chat/completions，模型 deepseek-chat
• 通义千问：endpoint https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions，模型 qwen-turbo
• 智谱 GLM：endpoint https://open.bigmodel.cn/api/paas/v4/chat/completions，模型 glm-4-flash

🎙️ 语音选择 (TTS)

推荐选择带 ⭐ 的神经/自然语音（Microsoft Aria Online / Google US English）—— 发音最接近真人播音员。首次打开可能需要等系统加载。

朗读参数（全局）

默认 1.0 / 1.0 / 1.0 = 广播标准语速。觉得偏快偏慢可以调整。
